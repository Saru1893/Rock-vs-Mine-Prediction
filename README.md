# 🚢 Rock vs Mine Prediction using Machine Learning

## 📌 Overview
This project predicts whether an underwater object is a **Rock** or a **Mine** using sonar signal data and a Logistic Regression model.

## 📊 Dataset
- Sonar Dataset
- 208 samples
- 60 numerical features
- Binary Classification: Rock (R) / Mine (M)

## 🛠️ Technologies Used
- Python
- NumPy
- Pandas
- Scikit-learn
- Google Colab

## ⚙️ Model Used
- Logistic Regression

## 📈 Results
- Training Accuracy: ~83%
- Testing Accuracy: ~76%
